Option 1 - Smart Classroom Comfort Monitor 
1. Allow the user to enter classroom temperature readings in Fahrenheit
2. Determine whether a temperature is within the acceptable range of 68F - 76F, inclusive
3. Display an appropiate NORMAL or WARNING status
4. Calculate the average of the recorded temperatures. 
5. Save temperature readings and their statuses to a filE.
6. Use an LED connected to the Raspberry Pi to indicate a warning condition.
7. Allow the acceptable temperature range to be changed according to a new client requirement.
